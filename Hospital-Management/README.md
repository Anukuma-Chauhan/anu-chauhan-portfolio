# Hospital Management System

## Project Overview

A Django-based Hospital Management System designed to manage doctors, patients, appointments, and user authentication.

## Features

- User authentication
- Doctor management
- Patient management
- Appointment management
- Doctor availability
- Patient and doctor records
- Appointment scheduling
- Django REST API
- Responsive web interface

## Technologies Used

- Python
- Django
- Django REST Framework
- HTML
- CSS
- JavaScript
- SQLite

This project was developed as a practical Django project to demonstrate web development, database management, authentication, and CRUD operations.
